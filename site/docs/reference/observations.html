Observations

An observation is what a source says an agent did: testimony, never a decision. The plane never reads one, and nothing in it grants or refuses a call (ADR-0039). The record is guardana.control.observe.v1alpha1, versions 0.1 to 0.3, outside the v1 compatibility promise (ADR-0040). It is experimental; status.md is the inventory.

The source descriptor

The operator's JSON file describing one source, read under the stores' owner checks. Every member is matched exactly; an unknown member, a member given twice or null is refused by name. The kind decides its further members, and another kind's member is refused (ADR-0069):

Kind Its members TRUST_INDEPENDENT Names a run
otel-genai-traces the four below refused: the agent's own process writes the spans yes
egress-access-log egress_access_log, on egress access log allowed, unsigned no
Member Required Value
schema_version yes 0.1; 0.2 exactly when it carries egress_access_log
source_id yes 1 to 128 characters of A-Z a-z 0-9 . _ : -
kind yes a kind above
trust yes TRUST_SELF_REPORTED, TRUST_PLATFORM, or TRUST_INDEPENDENT where the kind allows it
convention otel-genai-traces {"name": "opentelemetry.gen_ai", "version": "1.41.0"}; no other version of these developing conventions is read
otlp_version otel-genai-traces 1.11.1
select.service_name otel-genai-traces the service.name of the resource whose spans are this source's; spans of other resources are not imported
sampling no SAMPLING_COMPLETE or SAMPLING_PARTIAL; absent or unspecified reads as partial, which coverage prints as sampled
heartbeat_seconds yes 1 to 604800: how long the source may stay silent before coverage finds its paths unknown
tenant_id, project_id yes as source_id
run_attribute no the span attribute that names a run; never a content attribute

Text values may not hold a control or format character, nor be only whitespace, nor pass 256 bytes.

What an import keeps

A span of the selected resource becomes an observation when its gen_ai.operation.name is execute_tool (a tool, named by gen_ai.tool.name), invoke_agent or create_agent (an agent, gen_ai.agent.name), or chat, generate_content, text_completion or embeddings (a model, gen_ai.request.model). Any other span is skipped and counted by reason: no_operation, unmapped_operation, or one of the two operations the conventions name that this importer does not map, operation:retrieval and operation:invoke_workflow.

Only these are copied: the operation, the name above, gen_ai.provider.name, server.address, error.type and the run attribute. A copied string longer than 256 bytes, made only of whitespace, or holding a control, format, line or paragraph separator, private-use or noncharacter code point or U+FFFD, is dropped and counted. A span's name and its status message are never copied.

Field From the span
event_time its end time; absent when it has none, never the time it was read
received_time the import's own clock reading, the same on every record of one import
stage failed when the status is error or error.type is present, completed when it ended, unknown otherwise
outcome.status the status as sent: unset, ok or error
correlation.trace_id, span_id, parent_span_id the span's ids, lowercase hex as the gateway records a call's trace; a span with no trace or span id, or a zero or upper-case id, or a status code outside 0 to 2, is refused
correlation.basis BASIS_CLAIMED when the run attribute holds run- and 32 lowercase hex digits, the form of a run an operator opened; any other value is dropped and counted, and the basis is BASIS_NONE. Whether the run exists is not checked

What an import drops

No content is kept: there is no redaction to apply to it, and a capture setting is refused. Every content attribute (gen_ai.input.messages, gen_ai.output.messages, gen_ai.system_instructions, gen_ai.tool.call.arguments, gen_ai.tool.call.result, gen_ai.tool.definitions, gen_ai.prompt, gen_ai.completion) and every other gen_ai.* attribute outside the list above is dropped and counted, on a span and on its events, and in the report wherever else the selected resource carries one; so is gen_ai.request.model on a span that is not a model's. Message parts are parsed only to count reasoning: a part of type reasoning or thinking is counted and nothing of it is kept; a value that is not an array of messages whose parts each name a type is counted as unparsed, never as none.

The log

One file, observations.jsonl, in a directory of the operator's account that no other account can reach, held by one writer at a time. Each line holds one observation or one import report. A span's observation id is derived from its tenant, project, source, trace and span, and a connection's from its content, so an input imported again writes nothing new: a record already in the log with the same content is a duplicate, and one whose content differs, apart from its receive time and the descriptor's digest, a conflict, not written, and the import exits 1. The observations an import keeps and its report are appended together and synced, the report last; after a crash in that append, the next open cuts everything after the last whole report; a tail no writer of this package leaves is refused, not cut. An append that would take the file past 1 GiB is refused and writes nothing: the log is then rotated by hand.

Each import ends with one report: the source, the descriptor's SHA-256, the receive time, the input's first-line digest and size, every count above, and the earliest and latest event time. A source was last heard at its newest event time not later than a report's receive time.

A refused span was never written, and either copy of a conflict may be the false one, so each may hide a call of the run it claimed. The report's doubted_run_ids names those runs, ascending, at most 64: a refused span's, and both copies' of a conflict, save a kept copy that claims no run. A refused copy that claims no run, a line refused before its spans are read, or a 65th run sets every_run_doubted instead. A report that counts a refusal or a conflict and names no run, as a 0.1 report does, is read as doubting every run; supervision says what a doubted run leaves unchecked. A source's doubt is read from its own reports alone, those naming its source, tenant, project and kind, as its liveness is. supervise refuses a --source whose tenant or project is not the run's, and one whose kind names no run.

source.kind names a record's kind, empty for otel-genai-traces; a log takes one kind per source.

A record carrying a connection, refused_by, callers_dropped or a kind is 0.3, a report carrying a doubt member 0.2, any other 0.1; the reader refuses a version its members do not call for. A reader whose table lacks a version, as 0.14's lacks 0.3, refuses each such line.

A doubt has no time bound, and a doubt of every run reaches every later run of the source. Only rotating the log ends it: with no import running, move observations.jsonl out of its directory. Its observations go with it; until the next import starts a new file, supervise finds the source never heard.

Commands

guardana-control observe import --source <descriptor> --log <dir> <file>
guardana-control observe export [--after <cursor>] [--limit <n>] [--max-bytes <n>] <file>

import reads the input with its kind's importer (access logs). Spans come as OTLP/JSON trace lines, one TracesData object per line as an OpenTelemetry collector's file exporter writes them, up to the last newline; the bytes after it are left for the next import, since the exporter may still be writing them. A line with an unknown member, a member twice, an attribute twice, a null, an enum spelled as a string, nesting deeper than 32 or more than 262,144 array elements is refused, and every span in it is counted as refused. A line over 16 MiB is refused. The import reads its whole input, at most 256 MiB, into memory. Exit 0: everything read was imported, skipped or a duplicate. Exit 1: something was refused or conflicted. Exit 2: the import did not complete, for a usage error, a refused descriptor or log, or a failed write; a write refused after its sync, or a log that would not close, can leave the import in the log, and importing the same file again counts it as duplicates.

export writes guardana.control.observation-export version 0.1, in the evidence export's shape (ADR-0035): a header, observation and import_report records, gaps (malformed, unsupported_version, carriage_return, conflicting_observation_id, too_long, partial_tail), duplicates and a trailer with the cursor to resume from, and the same exit codes. It has no filters. It reads only a file the writer would open: a regular file of this account, not a link, that the group and others cannot reach, with no other name. It reads to the last import report, as a writer keeps the log: what follows is a write still open, or one a crash left that the next writer cuts, counted in the trailer's tail_bytes while a writer holds the log and a partial_tail gap when none does. The bytes after that report are read back from the end and left out of scanned_bytes. A log over the size bound, or whose lines after that report no writer leaves, is read to its last newline. Each line after the report is judged alone, so one that repeats an earlier id with other contents, which no writer leaves, counts in that gap rather than as a conflict.
