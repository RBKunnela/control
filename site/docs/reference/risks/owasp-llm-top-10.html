OWASP Top 10 for LLM Applications

OWASP's release record dates the 2026 edition to 2026-08-04. The download page is dated 2026-08-03. The identifiers and titles below follow the final list. Release record, download page, and edition PDF, read 2026-11-20.

Risks

Each test verifies a specific effect. For example, a mail server can receive no mail even after the run read untrusted content. The gateway enforcement examples use ENFORCE.

  • LLM01:2026 Prompt Injection

    Exercised control
    Model Context Protocol (MCP) gateway (experimental). A flow rule blocks outbound mail after the run reads untrusted content and confidential data. This limits one possible effect of an injection.
    Test file and function
    internal/gateway/e2e/flow_test.go · TestTheToxicFlowIsDeniedAcrossSessions. B37 mail cases.
    Known bypass and remaining gap
    Injected instructions in a tool result can reach the model. Prompt-injection detection and actions outside the tracked flow remain gaps. Threat model.

  • LLM02:2026 Sensitive Information Disclosure

    Exercised control
    Model Context Protocol (MCP) gateway (experimental). After reading untrusted content and then confidential data, the run cannot send mail through the tested external mail tool.
    Test file and function
    internal/gateway/e2e/flow_test.go · TestTheToxicFlowIsDeniedAcrossSessions. B37 case with order data in the mail.
    Known bypass and remaining gap
    A direct connection can bypass the mail tool. The model can also disclose data in its own reply. Threat model.

  • LLM03:2026 Excessive Agency

    Exercised control
    Approval binding (implemented). The transfer waits for approval. Once approved, the retried call can run only once.
    Test file and function
    internal/gateway/e2e/approval_test.go · TestPendingApprovalAndItsRetry. B37 changed-update case.
    Known bypass and remaining gap
    An overly broad allow rule can admit a harmful call. The operator chooses which actions require approval and which other paths the agent can reach. Threat model.

  • LLM04:2026 Supply Chain

    Exercised control
    Gap.
    Test file and function
    No test verifies the provenance of a model, training dataset, or model adapter.
    Known bypass and remaining gap
    Replacing a model artifact can change its behavior without changing a routed tool call. The model is outside the plane. Threat model.

  • LLM05:2026 Data and Model Poisoning

    Exercised control
    Gap.
    Test file and function
    No test checks training data or model weights for poisoning.
    Known bypass and remaining gap
    A poisoned model can give a harmful answer without calling a tool. The model and its training are outside the plane. Threat model.

  • LLM06:2026 Unbounded Consumption

    Exercised control
    Gap.
    Test file and function
    No test enforces a token, inference, or spending budget.
    Known bypass and remaining gap
    Repeated inference can incur cost without an MCP call. B42 covers usage and cost observations. A spending limit remains a gap.

  • LLM07:2026 Misinformation

    Exercised control
    Gap.
    Test file and function
    No test checks whether a model's answer is true.
    Known bypass and remaining gap
    False text from a tool can reach the model and be repeated to a reader. Threat model.

  • LLM08:2026 Hidden Context Exposure

    Exercised control
    Withholding an answer that quotes a credential (experimental). A tool definition that quotes a scanned credential is withheld from the tool list before it enters model context.
    Test file and function
    adapters/mcp/withhold_manifest_test.go · TestADefinitionQuotingASecretIsNeverListed.
    Known bypass and remaining gap
    A hostile server can disguise a credential. System prompts, private instructions, and secrets supplied by other routes are outside this check. Threat model.

  • LLM09:2026 Vector and Embedding Weaknesses

    Exercised control
    Gap.
    Test file and function
    No test checks vector-store access, embedding integrity, or isolation between users' search results.
    Known bypass and remaining gap
    An allowed search can retrieve another user's records or a poisoned result. The gateway cannot inspect the server's retrieval process. Threat model.

  • LLM10:2026 Improper Output Handling

    Exercised control
    Model Context Protocol (MCP) gateway (experimental), for two arguments of one configured transfer tool. OWASP includes validation before model output reaches a backend function. In the test, the server receives amount capped from 5000 to 1000 and the ssn field is removed. OWASP mitigation 1, p. 56 and obligations.
    Test file and function
    internal/gateway/e2e/call_test.go · TestRewritingObligationReachesTheWire checks the arguments received by the server. internal/gateway/rewrite_test.go · TestRewriteRefusesWhatItCannotApply checks malformed arguments, including a string in the numeric field.
    Known bypass and remaining gap
    The test client supplies the arguments. Other fields pass through, and the receiving application controls how it uses them. Safe handling of generated SQL, shell commands, or browser content remains a gap. Threat model.

What B37 measured

Controlled attempts counted at the victim (experimental) checks what the demo's order and mail tools received. The results include legitimate updates held for approval. The fixture uses scripted calls and measures no model output. B37 results and counting method.
