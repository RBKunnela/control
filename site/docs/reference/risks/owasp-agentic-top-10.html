OWASP Top 10 for Agentic Applications

OWASP published the 2026 edition on 2025-12-09. The identifiers and risk titles come from that edition. Guardana Control maps each risk to the behavior its tests exercise. OWASP edition page and published report, read 2026-11-20.

Risks

The gateway examples use ENFORCE. In OBSERVE, the gateway records a policy denial and lets the call run. A gap means there is no exercised control for the behavior described. Threat model.

  • ASI01: Agent Goal Hijack

    Exercised control
    Model Context Protocol (MCP) gateway (experimental). A flow rule blocks outbound mail if the run previously read untrusted content and confidential data. This limits one way a steered agent can send data out.
    Test file and function
    internal/gateway/e2e/flow_test.go · TestTheToxicFlowIsDeniedAcrossSessions. B37 mail cases.
    Known bypass and remaining gap
    Goal hijacking itself can go undetected. User prompts and tool descriptions fall outside the tracked flow, and a changed goal can lead to a harmful call that policy allows. Threat model.

  • ASI02: Tool Misuse and Exploitation

    Exercised control
    Model Context Protocol (MCP) gateway (experimental). A delete denied by policy never reaches the tool server.
    Test file and function
    internal/gateway/e2e/call_test.go · TestDeniedCallNeverReachesTheUpstream. B37 refund case.
    Known bypass and remaining gap
    An agent can bypass the gateway by reaching the server directly. It can also misuse a tool that policy allows. Threat model.

  • ASI03: Identity and Privilege Abuse

    Exercised control
    Decision kernel (implemented), exercised with delegation chains supplied by a kernel unit test. The kernel denies an expired chain, a cycle, or a child scope wider than its parent's.
    Test file and function
    internal/core/decide_test.go · TestDelegationRefusalIsABuiltInDeny. The MCP path is exercised separately in internal/gateway/e2e/classes_test.go · TestEveryEffectClassUnderEveryAnswer.
    Known bypass and remaining gap
    The live MCP listener uses its configured principal for every caller and supplies no delegation chain. In ENFORCE, a SPAWN_OR_DELEGATE call gets REQUIRED_FIELD_ABSENT before the delegation check. End-user authentication and enforcement of a caller's delegation chain remain gaps on this path, and no backlog task covers them. MCP coverage.

  • ASI04: Agentic Supply Chain Vulnerabilities

    Exercised control
    Model Context Protocol (MCP) gateway (experimental). A tool whose definition changes upstream at run time becomes unclassified until it is classified again. Its call is blocked.
    Test file and function
    adapters/mcp/list_test.go · TestListChangedRefreshesTheManifest.
    Known bypass and remaining gap
    An operator can pin a hostile definition, and server behavior can change behind an unchanged definition. Threat model. Tool-definition change review is planned in B25.

  • ASI05: Unexpected Code Execution (RCE)

    Exercised control
    Gap.
    Test file and function
    No test exercises process containment.
    Known bypass and remaining gap
    The agent can run code directly, and an allowed tool can execute code on its host. Host process events are planned in B35 for observation. Host isolation remains a gap. Threat model.

  • ASI06: Memory & Context Poisoning

    Exercised control
    Gap.
    Test file and function
    No test exercises agent memory integrity.
    Known bypass and remaining gap
    Injected text in a tool result can reach the agent. No exercised check governs what enters persistent memory or what a later task retrieves. Threat model.

  • ASI07: Insecure Inter-Agent Communication

    Exercised control
    Gap.
    Test file and function
    No test exercises peer authentication or message integrity on an agent-to-agent channel.
    Known bypass and remaining gap
    Peers can communicate outside the plane. The Agent-to-agent (A2A) adapter is planned. B16 includes adapter conformance.

  • ASI08: Cascading Failures

    Exercised control
    Gap. OWASP describes a fault that spreads and grows as other agents, tools, or workflows act on it. ASI08, report p. 30.
    Test file and function
    internal/gateway/decisionpoint_test.go · TestSilenceBlocksEveryEffectClassUnderEnforce checks one authorization at a time. An unanswered external veto blocks the call that needed it.
    Known bypass and remaining gap
    A wrong result can pass to another agent and trigger further allowed actions. The test exercises neither detection of that spread nor recovery of the affected workflow. Decision-point limits.

  • ASI09: Human-Agent Trust Exploitation

    Exercised control
    Approval binding (implemented). An approved transfer runs once. A repeated request cannot reuse the approval.
    Test file and function
    internal/gateway/e2e/approval_test.go · TestPendingApprovalAndItsRetry. B37 changed-update case.
    Known bypass and remaining gap
    A person can still be persuaded to approve the original harmful transfer. B38 covers showing the exact action to the approver.

  • ASI10: Rogue Agents

    Exercised control
    Stopping a run through a signed route (experimental). When a child is denied mail and retries it to another address, also denied, supervise confirms the repeated denials, and a signed route naming that rule stops later calls by the child. The retry finding itself is suspected and stops nothing.
    Test file and function
    cmd/guardana-gateway/reaction_tree_unix_test.go · TestAChildsRetryIsSupervisedOverTheTreeAndStopsTheChild.
    Known bypass and remaining gap
    The parent can still act. A call already running can finish, and the child can use a path outside the gateway. Continuous checks are work in B28. Threat model.

What B37 measured

Controlled attempts counted at the victim (experimental) compares the demo victims' journals under ENFORCE and OBSERVE. The results show which scripted effects reached the victims and the cost to legitimate work, including updates held for approval. A script chose the calls. B37 results and counting method.
