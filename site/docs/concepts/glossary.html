Glossary

One name per concept. A page uses the name in the left column and no other for the same thing; the right column is where the code defines it.

Name Meaning Defined in
action digest the canonical digest of an envelope with its authorized arguments, sha256: and 64 lowercase hex digits; what a decision names unless it refused the envelope or its arguments, an approval binds to and the executed bytes are compared with canon.DigestV1 in internal/canon/digest.go
action envelope the structured description of one proposed action: who, on behalf of whom, what, on which resource, in which context, with which effect class; the input every decision is made from ActionEnvelope in api/proto/guardana/control/v1/action_envelope.proto, validated by pkg/contract
approval binding the digest of an action digest under one policy bundle digest; what an approval is stored and compared against canon.ApprovalBinding, approval.Bind in internal/core/approval/
binding a name a 0.2 procedure gives one resource type; the steps and allowed tools that list it in binds must keep to one resource of that type, or RESOURCE_OUTSIDE_RUN fires. Not an approval binding Binding in internal/supervise/procedure_v02.go, reference/supervision
bundle a signed policy document with its reference, bundle_id, version and digest, and a serial inside the signed document; verified before it is trusted and installed as a snapshot PolicyBundle in api/proto/guardana/control/v1/bundle.proto, internal/policy/bundle/
channel a way an agent's actions reach Control: through an enforcement point, which decides before the effect, or a sensor, which reports after it; MCP is the first, and the OpenTelemetry GenAI trace importer the first sensor ADR-0039; the importer experimental, other channels planned
children mode what a 0.2 procedure's children says of the runs opened under the supervised one: inherit judges a root run and its whole run tree, separate judges one run's own calls and lists its children Children in internal/supervise/procedure_v02.go, ChildrenMode in api/proto/guardana/control/finding/v1alpha1/report.proto
coverage for each path an operator declared, whether it is enforced, decided but not enforced, observed with its source's trust, unknown or not covered; paths nobody declared are unknown too, and it is never a percentage internal/coverage/, run by guardana-control coverage, experimental
decision what the kernel, or the enforcement point on its own behalf, concluded about one envelope: a verdict, its reason codes, the rules and obligations, the action digest and the bundle digest Decision in api/proto/guardana/control/v1/decision.proto, made in internal/core/decide.go
effect class the kind of consequence an action has, READ or one of the material classes; what materiality, the fail-closed table and the contract's required fields turn on EffectClass in common.proto, contract.IsMaterial in pkg/contract/effect.go
enforcement mode what the enforcement point does with a decision: OBSERVE, APPROVE, ENFORCE or LOCKDOWN in this build; never what is decided EnforcementMode in common.proto, internal/gateway/mode.go
enforcement point the process that runs one pipeline with an adapter, a sink and a policy source, and whose own record a hold, a halt and a block it minted live in; cmd/guardana-gateway in this build cmd/guardana-gateway/main.go, wiring Pipeline in internal/gateway/pipeline.go
evidence export a trail file's events written to standard output in the versioned format guardana.control.evidence-export: a header, one record per event, gap or duplicate, and a trailer that says whether the file's end was reached trailfile.Export in internal/trailfile/export.go, run by guardana-gateway trail export
evidence trail the chain of events under one request id, from ACTION_PROPOSED to the event that closes it, linked by prev_event_id; a request in flight or held has a prefix of one evidence.Builder in internal/evidence/event.go, validated by internal/evidence/chain.go
exception a 0.2 procedure's waiver of one rule for one step, or for STEP_OUTSIDE_PROCEDURE one tool on one upstream, taken on one condition: an approval granted, a step failed or a reason code; taking one raises EXCEPTION_TAKEN, never a stronger finding than the one it waived Exception in internal/supervise/procedure_v02.go, applied in internal/supervise/exceptions.go
execution one run of an authorized call, named by the execution_id that ACTION_STARTED carries and the closing event repeats; a trail allows one Builder.Started in internal/evidence/event.go, kept by internal/gateway/trails.go
export cursor where an evidence export stopped: the digest of the file's first line, an offset after a newline and the digest of the line that ends there; refused when the file's first line or the line ending at the offset differs. Not the exporter's cursor in the spool cursor in internal/lineexport/cursor.go
external decision point the organization's own policy engine, asked over AuthZEN about a call whose decision turns on its answer; the answer is an input a DENY rule reads, so it can veto and never grant, and its silence blocks in every mode that enforces gateway.DecisionPoint in internal/gateway/decisionpoint.go, the answer as core.External in internal/core/external.go, the client in adapters/authzen/
fail-open read a read the kernel lets run although the policy's availability left it undecided, under the operator's explicit setting and recorded as FAIL_OPEN_READ_CONFIGURED; never a material call Options.FailOpenRead in internal/core/kernel.go, the table in internal/core/failclosed.go
finding what a detector concludes about a run, CONFIRMED, SUSPECTED or INDETERMINATE, citing the evidence and observations it rests on; it never grants authority and never changes a verdict Finding in finding.proto, inside the FindingRecord that guardana-control supervise writes, experimental
findings log one directory's findings.jsonl, to which supervise appends a run's findings and its report under an exclusive lock; what notify, react and findings export read findinglog.Log in internal/findinglog/log.go
freshness statement a signed claim, under a key apart from the bundle's, that one bundle id, serial and digest was current at its issuedAt; the only thing that confirms a snapshot, for the policy's staleness budget from that time policy.Statement in internal/policy/statement.go, written by guardana-control policy renew
gap an export record for a line that is not one readable record of a major the build reads, or that reuses an id with other content; a whole export holding one exits 1 gapRecord in internal/lineexport/records.go
import report the record an import appends after the observations it kept: the source, the receive time, the input's size and first line's digest, the counts, and the earliest and latest event times; what says when a source was last heard ImportReport in api/proto/guardana/control/observe/v1alpha1/observation.proto
held request a request awaiting an approval that the enforcement point keeps in its own record, answered at once with a pending state and resumed by a retry that equals it heldRequest in internal/gateway/trails.go, Held in internal/gateway/approvals.go
manifest what the upstreams list plus the operator's classification of each definition, pinned by fingerprint; where a tool's effect class, resource type and trust zone come from adapters/mcp/manifest.go
notifier a port that delivers findings to a tool an operator watches, at least once, each with a stable id a receiver drops repeats by; it holds no authority over a plane internal/notify/, run by guardana-control notify, which hands alerts to a local program, experimental; other notifiers planned
obligation a condition on a call that proceeds, carried by an ALLOW_WITH_OBLIGATIONS or REQUIRE_APPROVAL rule; who applies each type, and what happens to one nobody applies, is on the obligations reference Obligation in decision.proto, the catalogue in internal/policy/rules/, internal/gateway/rewrite.go
observation what a sensor reports a source saw, with the source, its trust, the event's time if known and the basis of any correlation; testimony, never a decision or evidence of enforcement ADR-0040, reference/observations.md
observation log one directory's observations.jsonl, appended under one writer's lock with each import's observations and its report, and read through the observation export internal/observelog/log.go
pipeline the protocol-neutral enforcement pipeline an enforcement point runs: Admit, Preview, Close and Abort, the mode, the trail and the holds Pipeline in internal/gateway/pipeline.go
principal the party an action is done for, with its tenant, type, id and authentication strength; on a listener it comes from the operator's configuration or the authenticator, never from a client's claim Principal in action_envelope.proto, identity in adapters/mcp/translate.go
procedure the operator's JSON document of a run's steps, their order, the tools it may also call and each rule's severity and escalation; what supervise judges one opened run against, recorded by its digest Procedure, ReadProcedure in internal/supervise/procedure.go, reference/supervision
quarantine the spool's file for records a collector refused for good, appended to and never released, so the exporter's cursor passes them without dropping them Reader.Quarantine in internal/spool/quarantine.go
reaction turning a finding the operator's signed route allows into a stop of the one run it is about, which the enforcement points apply to that run's later calls, for a scope and an expiry; separate from the notifier ADR-0039, internal/reaction/, reference/reaction, experimental for one opened run from a confirmed finding
reason code the identifier of the kind of failure or match a decision carries, from the registry; never derived from error text, and never read to decide internal/policy/reasons/, listed in reference/reason-codes
record one event as the spool writes it to disk, a header and one JSON line, checksummed; the unit the spool appends, reads, acknowledges and quarantines internal/spool/frame.go
run tree the runs a 0.2 report lists with the supervised run, each naming its parent: under inherit the root's whole tree, every member judged; under separate the run's children, not judged RunTreeMember in api/proto/guardana/control/finding/v1alpha1/report.proto
run view the static HTML page supervise --view draws of one supervised run, its steps, findings and marked calls; it judges nothing itself runview.Page in internal/runview/view.go, reference/run-view
sensor a port that sees an effect after it happened, or an indirect sign of it, and reports it as observations; it never decides; the OpenTelemetry GenAI trace importer is one ADR-0039, internal/ingest/otelgenai/, experimental; others planned
serial floor the newest statement a plane or a signer has accepted for a bundle id, kept on disk; a bundle below it, or at its serial with another digest, is refused, across restarts policy.Floor in internal/policy/floor.go, stored by internal/policystate/
snapshot one verified, compiled bundle, with the issuedAt of the statement that confirmed it or none; never changed after it is made, so a call is decided against exactly one policy.Snapshot in internal/policy/policy.go, served by policy.Holder
source descriptor the operator's JSON statement about one source: its kind, trust, convention, selector, sampling and heartbeat; read under owner checks, never taken from the data observe.ReadDescriptor in internal/observe/descriptor.go
spool the evidence sink that writes disk: an append-only, checksummed, bounded log an exporter drains and acknowledges spool.Spool in internal/spool/spool.go
trail file the collector's append-only file of events, one per line in the protobuf JSON mapping, each event id once; what trail and trail export read trailfile.Writer in internal/trailfile/writer.go
trust how far an observation's source can be believed, from its descriptor: TRUST_SELF_REPORTED (the agent's own process), TRUST_PLATFORM (the platform it runs on) or TRUST_INDEPENDENT (something the agent cannot influence) Trust in api/proto/guardana/control/observe/v1alpha1/source.proto
unrecorded read a read that ran with a trail the sink did not take, under the explicit evidence setting; counted, never held and never closed Config.AllowReadsUnrecorded in internal/gateway/config.go
verdict one of the five outcomes of a decision: DENY, INDETERMINATE, REQUIRE_APPROVAL, ALLOW_WITH_OBLIGATIONS, ALLOW; INDETERMINATE is never ALLOW Verdict in common.proto, internal/core/decide.go
verified time the latest issuedAt the plane verified, from a statement it confirmed or its floor's latest; a clock reading behind it decides nothing Snapshot.NotBefore in internal/policy/policy.go
