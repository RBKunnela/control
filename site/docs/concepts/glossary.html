Glossary

One name per concept. A page uses the name in the left column and no other for the same thing; the right column is where the code defines it.

  • action digest

    Meaning
    the canonical digest of an envelope with its authorized arguments, sha256: and 64 lowercase hex digits; what a decision names unless it refused the envelope or its arguments, an approval binds to and the executed bytes are compared with
    Defined in
    canon.DigestV1 in internal/canon/digest.go

  • action envelope

    Meaning
    the structured description of one proposed action: who, on behalf of whom, what, on which resource, in which context, with which effect class; the input every decision is made from
    Defined in
    ActionEnvelope in api/proto/guardana/control/v1/action_envelope.proto, validated by pkg/contract

  • approval binding

    Meaning
    the digest of an action digest under one policy bundle digest; what an approval is stored and compared against
    Defined in
    canon.ApprovalBinding, approval.Bind in internal/core/approval/

  • binding

    Meaning
    a name a 0.2 procedure gives one resource type; the steps and allowed tools that list it in binds must keep to one resource of that type, or RESOURCE_OUTSIDE_RUN fires. Not an approval binding
    Defined in
    Binding in internal/supervise/procedure_v02.go, reference/supervision

  • bundle

    Meaning
    a signed policy document with its reference, bundle_id, version and digest, and a serial inside the signed document; verified before it is trusted and installed as a snapshot
    Defined in
    PolicyBundle in api/proto/guardana/control/v1/bundle.proto, internal/policy/bundle/

  • carry

    Meaning
    stops init --carry: a new stop list begun from an old one, judged by the old route, holding each stop of the old list no lift ended, expired or not, and a covered line for every other finding it names; the old list stays locked until the new one is written; the one way a list moves to another route or format
    Defined in
    Carry and CarrySigned in internal/reaction/stopwrite/carry.go, reference/reaction

  • channel

    Meaning
    a way an agent's actions reach Control: through an enforcement point, which decides before the effect, or a sensor, which reports after it; MCP is the first, the OpenTelemetry GenAI trace importer the first sensor, and an egress proxy's access log the second
    Defined in
    ADR-0039; both importers experimental, other channels planned

  • children mode

    Meaning
    what a 0.2 procedure's children says of the runs opened under the supervised one: inherit judges a root run and its whole run tree, separate judges one run's own calls and lists its children
    Defined in
    Children in internal/supervise/procedure_v02.go, ChildrenMode in api/proto/guardana/control/finding/v1alpha1/report.proto

  • coverage

    Meaning
    for each path an operator declared, whether it is enforced, decided but not enforced, observed with its source's trust, unknown or not covered; paths nobody declared are unknown too, and it is never a percentage
    Defined in
    internal/coverage/, run by guardana-control coverage, experimental

  • decision

    Meaning
    what the kernel, or the enforcement point on its own behalf, concluded about one envelope: a verdict, its reason codes, the rules and obligations, the action digest and the bundle digest
    Defined in
    Decision in api/proto/guardana/control/v1/decision.proto, made in internal/core/decide.go

  • effect class

    Meaning
    the kind of consequence an action has, READ or one of the material classes; what materiality, the fail-closed table and the contract's required fields turn on
    Defined in
    EffectClass in common.proto, contract.IsMaterial in pkg/contract/effect.go

  • enforcement mode

    Meaning
    what the enforcement point does with a decision: OBSERVE, APPROVE, ENFORCE or LOCKDOWN in this build; never what is decided
    Defined in
    EnforcementMode in common.proto, internal/gateway/mode.go

  • enforcement point

    Meaning
    the process that runs one pipeline with an adapter, a sink and a policy source, and whose own record a hold, a halt and a block it minted live in; cmd/guardana-gateway in this build
    Defined in
    cmd/guardana-gateway/main.go, wiring Pipeline in internal/gateway/pipeline.go

  • evidence export

    Meaning
    a trail file's events written to standard output in the versioned format guardana.control.evidence-export: a header, one record per event, gap or duplicate, and a trailer that says whether the file's end was reached
    Defined in
    trailfile.Export in internal/trailfile/export.go, run by guardana-gateway trail export

  • evidence trail

    Meaning
    the chain of events under one request id, from ACTION_PROPOSED to the event that closes it, linked by prev_event_id; a request in flight or held has a prefix of one
    Defined in
    evidence.Builder in internal/evidence/event.go, validated by internal/evidence/chain.go

  • exception

    Meaning
    a 0.2 procedure's waiver of one rule for one step, or for STEP_OUTSIDE_PROCEDURE one tool on one upstream, taken on one condition: an approval granted, a step failed or a reason code; taking one raises EXCEPTION_TAKEN, never a stronger finding than the one it waived
    Defined in
    Exception in internal/supervise/procedure_v02.go, applied in internal/supervise/exceptions.go

  • execution

    Meaning
    one run of an authorized call, named by the execution_id that ACTION_STARTED carries and the closing event repeats; a trail allows one
    Defined in
    Builder.Started in internal/evidence/event.go, kept by internal/gateway/trails.go

  • export cursor

    Meaning
    where an evidence export stopped: the digest of the file's first line, an offset after a newline and the digest of the line that ends there; refused when the file's first line or the line ending at the offset differs. Not the exporter's cursor in the spool
    Defined in
    cursor in internal/lineexport/cursor.go

  • external decision point

    Meaning
    the organization's own policy engine, asked over AuthZEN about a call whose decision turns on its answer; the answer is an input a DENY rule reads, so it can veto and never grant, and its silence blocks in every mode that enforces
    Defined in
    gateway.DecisionPoint in internal/gateway/decisionpoint.go, the answer as core.External in internal/core/external.go, the client in adapters/authzen/

  • fail-open read

    Meaning
    a read the kernel lets run although the policy's availability left it undecided, under the operator's explicit setting and recorded as FAIL_OPEN_READ_CONFIGURED; never a material call
    Defined in
    Options.FailOpenRead in internal/core/kernel.go, the table in internal/core/failclosed.go

  • finding

    Meaning
    what a detector concludes about a run, CONFIRMED, SUSPECTED or INDETERMINATE, citing the evidence and observations it rests on; it never grants authority and never changes a verdict
    Defined in
    Finding in finding.proto, inside the FindingRecord that guardana-control supervise writes, experimental

  • findings log

    Meaning
    one directory's findings.jsonl, to which supervise appends a run's findings and its report under an exclusive lock; what notify, react and findings export read
    Defined in
    findinglog.Log in internal/findinglog/log.go

  • freshness statement

    Meaning
    a signed claim, under a key apart from the bundle's, that one bundle id, serial and digest was current at its issuedAt; the only thing that confirms a snapshot, for the policy's staleness budget from that time
    Defined in
    policy.Statement in internal/policy/statement.go, written by guardana-control policy renew

  • gap

    Meaning
    an export record for a line that is not one readable record of a major the build reads, or that reuses an id with other content; a whole export holding one exits 1
    Defined in
    gapRecord in internal/lineexport/records.go

  • health socket

    Meaning
    the Unix socket health.socket names; the plane serves its whole health answer there, with the run ids and signers /healthz leaves out, to its own account and to health.socket_uid, and closes any other peer unanswered
    Defined in
    bindHealthSocket in cmd/guardana-gateway/health_socket.go

  • import report

    Meaning
    the record an import appends after the observations it kept: the source, the receive time, the input's size and first line's digest, the counts, and the earliest and latest event times; what says when a source was last heard
    Defined in
    ImportReport in api/proto/guardana/control/observe/v1alpha1/observation.proto

  • held request

    Meaning
    a request awaiting an approval that the enforcement point keeps in its own record, answered at once with a pending state and resumed by a retry that equals it
    Defined in
    heldRequest in internal/gateway/trails.go, Held in internal/gateway/approvals.go

  • lift

    Meaning
    a signed line of the stop list that ends every stop of one run, or under signed of one scope and subject, up to and including a line it names; under signed a roster operator granted operate signs it, otherwise the holder of the route's lift key
    Defined in
    Lift in internal/reaction/lift.go, SignedLiftV3 in internal/reaction/lift3.go, reference/reaction

  • manifest

    Meaning
    for the MCP gateway, what the upstreams list plus the operator's classification of each definition, pinned by fingerprint; where a tool's effect class, resource type and trust zone come from
    Defined in
    adapters/mcp/manifest.go

  • notifier

    Meaning
    a port that delivers findings to a tool an operator watches, at least once, each keyed by finding id and verdict, a key a receiver drops repeats by; it holds no authority over a plane
    Defined in
    internal/notify/, run by guardana-control notify, which hands alerts to a local program, experimental; other notifiers planned

  • obligation

    Meaning
    a condition on a call that proceeds, carried by an ALLOW_WITH_OBLIGATIONS or REQUIRE_APPROVAL rule; who applies each type, and what happens to one nobody applies, is on the obligations reference
    Defined in
    Obligation in decision.proto, the catalogue in internal/policy/rules/, internal/gateway/apply.go

  • observation

    Meaning
    what a sensor reports a source saw, with the source, its trust, the event's time if known and the basis of any correlation; testimony, never a decision or evidence of enforcement
    Defined in
    ADR-0040, reference/observations.md

  • observation log

    Meaning
    one directory's observations.jsonl, appended under one writer's lock with each import's observations and its report, and read through the observation export
    Defined in
    internal/observelog/log.go

  • pipeline

    Meaning
    the protocol-neutral enforcement pipeline an enforcement point runs: Admit, Preview, Close and Abort, the mode, the trail and the holds
    Defined in
    Pipeline in internal/gateway/pipeline.go

  • plane

    Meaning
    one running enforcement point with what it serves from: one configuration, one listener, MCP or the enforcement API, its policy, its spool and its state directories; under the signed authority it is named by plane_id and serves one tenant
    Defined in
    plane in cmd/guardana-gateway/build.go, run the gateway

  • port

    Meaning
    a decision about authority behind an interface, with a tested default kind, an unavailable answer that blocks, bounds and conformance cases; scripts/ports.txt lists the ports that exist, and a port's record states where it still falls short
    Defined in
    ADR-0066, testdata/ports/

  • principal

    Meaning
    the party an action is done for, with its tenant, type, id and authentication strength; on a listener it comes from the operator's configuration or the authenticator, never from a client's claim
    Defined in
    Principal in action_envelope.proto, identity in adapters/mcp/translate.go

  • procedure

    Meaning
    the operator's JSON document of a run's steps, their order, the tools it may also call and each rule's severity and escalation; what supervise judges one opened run against, recorded by its digest
    Defined in
    Procedure, ReadProcedure in internal/supervise/procedure.go, reference/supervision

  • quarantine

    Meaning
    the spool's file for records a collector refused for good, appended to and released only by an operator's spool drain, so the exporter's cursor passes them without dropping them
    Defined in
    Reader.Quarantine in internal/spool/quarantine.go

  • reaction

    Meaning
    turning a finding the operator's signed route allows into a stop of the run it is about or, under signed, of that run's agent or principal, which the enforcement points apply to later calls, for a scope and an expiry; separate from the notifier
    Defined in
    ADR-0039, ADR-0083, internal/reaction/, reference/reaction, experimental for one opened run, or its agent or principal, from a confirmed finding

  • reason code

    Meaning
    the identifier of the kind of failure or match a decision carries, from the registry; never derived from error text, and never read to decide
    Defined in
    internal/policy/reasons/, listed in reference/reason-codes

  • record

    Meaning
    one event as the spool writes it to disk, a header and one JSON line, checksummed; the unit the spool appends, reads, acknowledges and quarantines
    Defined in
    internal/spool/frame.go

  • roster operator

    Meaning
    a key the trust roster names for a person, granted a tenant, a project and a level: read, operate or admin, each including the one before; operate approves, pauses, and signs a run record, a stop list header and a lift, admin also a route
    Defined in
    RoleOperator and Level in internal/trust/format.go, the acts in internal/operators/answer.go

  • route

    Meaning
    the operator's signed document saying which confirmed findings may stop a run, and under signed its agent or principal: its tenant, under signed also its plane and project, and rules, each a procedure and a supervise rule; a plane reads it at start only
    Defined in
    Route in internal/reaction/route.go, reference/reaction

  • run

    Meaning
    the calls whose events share a run_id and whose flow state is kept together: without runs.dir, those of the listener's principal and agent, kept in memory and started clean at each restart; with it, those presenting the token of a run an operator opened
    Defined in
    runKey and run in internal/gateway/flow.go, internal/runs/, reference/runs

  • run tree

    Meaning
    the runs a 0.2 report lists with the supervised run, each naming its parent: under inherit the root's whole tree, every member judged; under separate the run's children, not judged
    Defined in
    RunTreeMember in api/proto/guardana/control/finding/v1alpha1/report.proto

  • run view

    Meaning
    the static HTML page supervise --view draws of one supervised run, its steps, findings and marked calls; it judges nothing itself
    Defined in
    runview.Page in internal/runview/view.go, reference/run-view

  • sensor

    Meaning
    a port that sees an effect after it happened, or an indirect sign of it, and reports it as observations; it never decides; the OpenTelemetry GenAI trace importer and the egress access-log importer are two
    Defined in
    ADR-0039, internal/ingest/otelgenai/, internal/ingest/egresslog/, experimental; others planned

  • serial floor

    Meaning
    the newest serial a plane or a signer has accepted, kept on disk in a floor directory of one kind: a bundle's (plane, signer), a trust roster's (authority), a route's, a signed pause file's or a stop list's; a document below it, or at its serial with another digest, is refused, across restarts
    Defined in
    policy.Floor in internal/policy/floor.go, the kinds in internal/policystate/

  • signed authority

    Meaning
    approvals.authority: signed; a plane under it, a signed plane, takes an approval, a pause, a run and a stop list only as a roster operator signed it for the plane's tenant and project. What it refuses at start is on set up signed operators, and the serial floors it keeps on signed operations
    Defined in
    AuthoritySigned in internal/gatewayconfig/config.go, ADR-0073, ADR-0075, ADR-0076, ADR-0077

  • signed run record

    Meaning
    a run record 3.0 in runs.dir's records/, signed by a roster operator granted operate for the run's tenant and project and bound to that directory; the only record a signed plane counts; the plane copies each close it takes into state/, so the run's open record put back later is refused
    Defined in
    SignedRecordVersion in internal/runs/signed.go, judged by internal/runs/signedruns/, reference/runs

  • snapshot

    Meaning
    one verified, compiled bundle, with the issuedAt of the statement that confirmed it or none; never changed after it is made, so a call is decided against exactly one
    Defined in
    policy.Snapshot in internal/policy/policy.go, served by policy.Holder

  • source descriptor

    Meaning
    the operator's JSON statement about one source: its kind, trust, the members its kind owns, sampling and heartbeat; read under owner checks, never taken from the data
    Defined in
    ingest.ReadDescriptor in internal/ingest/ingest.go, the kinds in internal/observe/kinds.go

  • spool

    Meaning
    the evidence sink that writes disk: an append-only, checksummed, bounded log an exporter drains and acknowledges
    Defined in
    spool.Spool in internal/spool/spool.go

  • stop

    Meaning
    a line of the stop list by which one confirmed finding stops the later calls of its run, or under signed of that run's agent or principal, until it expires or a lift ends it; a plane refuses those calls with RUN_STOPPED or AGENT_OR_PRINCIPAL_STOPPED
    Defined in
    Stop in internal/reaction/line.go, reference/reaction

  • stop list

    Meaning
    stops.jsonl in the directory reaction.stops names: a header naming the route, then stop, covered and lift lines, appended and never rewritten, which react and the stops commands write under the list's lock; a plane reads it every poll interval and takes no lock
    Defined in
    internal/reaction/stoplist/, internal/reaction/stopwrite/, reference/reaction

  • stop list header

    Meaning
    the first line of a stop list 3.0: an envelope over a reaction-list-header/3.0 body a roster operator signs, naming the list, its serial, the plane's plane_id, tenant, project and stop list file, the route and, for a list carried from another, the previous header's digest; a lift names it and the stop list floor keeps it
    Defined in
    HeaderSigned in internal/reaction/header2.go, reference/reaction-signed

  • trail file

    Meaning
    a file of events, one per line in the protobuf JSON mapping, each event id once; what trail and trail export read
    Defined in
    trailfile.Writer in internal/trailfile/writer.go

  • trail segments

    Meaning
    the directory the collector writes, bound to one tenant and project: sealed segments, each a trail file, a live one appends go to, and segments.json naming each, sealed or pruned; bounded in bytes, pruned only by an operator
    Defined in
    trailfile.Log in internal/trailfile/log.go over internal/segmentlog/

  • trust

    Meaning
    how far an observation's source can be believed, from its descriptor: TRUST_SELF_REPORTED (the agent's own process), TRUST_PLATFORM (the platform it runs on) or TRUST_INDEPENDENT (something the agent cannot influence)
    Defined in
    Trust in api/proto/guardana/control/observe/v1alpha1/source.proto

  • trust roster

    Meaning
    the signed file that names operator keys and the tenant, project and level each may act on, under a pinned root, for at most 7 days at a serial that only climbs; a plane reads one only under the signed authority, through trust.*
    Defined in
    internal/trust/, ADR-0071

  • unrecorded read

    Meaning
    a read that ran with a trail the sink did not take, under the explicit evidence setting; counted, never held and never closed
    Defined in
    Config.AllowReadsUnrecorded in internal/gateway/config.go

  • verdict

    Meaning
    one of the five outcomes of a decision: DENY, INDETERMINATE, REQUIRE_APPROVAL, ALLOW_WITH_OBLIGATIONS, ALLOW; INDETERMINATE is never ALLOW
    Defined in
    Verdict in common.proto, internal/core/decide.go

  • verified time

    Meaning
    the latest issuedAt the plane verified, from a statement it confirmed or its floor's latest; a clock reading behind it decides nothing
    Defined in
    Snapshot.NotBefore in internal/policy/policy.go
